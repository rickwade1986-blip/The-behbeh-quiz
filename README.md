# The Behbeh Quiz

**ODD COUPLE — Rick vs Laura**

A mobile-first private-lore chaos game built from Rick & Laura's chat history.

- 579-question bank
- Who Said It?
- Finish the Quote
- What Happened Next?
- Timeline Panic
- Music Nerd-Off
- Weird Shit
- Tap Pack
- Full Chaos
- Seen-question memory to minimise repeats
- Seeded challenge links for playing the same round on separate phones
- Mini-games including Tap O'Clock, Save the Savvy B, Find Rick's Glasses and Greggs Doctrine

The app is a static GitHub Pages site; no server or account is required.
